## 1. ❔ How to use
1. Download the [👻.zip](https://github.com/r7vv/pack/blob/main/%F0%9F%91%BB.zip) from the repo
2. Put it in your texture pack folder; usually inside `~AppData\Roaming\.minecraft\resourcepacks` on windows.
3. Apply in-game (put it on top, since it is an overlay)
   ![how to download](https://github.com/r7vv/pack/blob/main/tut.gif)
Enjoy
